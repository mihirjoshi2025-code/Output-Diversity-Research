# Ablation

**In one line:** an experiment where you add or remove one ingredient to see what it does.

**Example from the report (Table 18):** adding WildChat + OpenAssistant chat data to SFT raised AlpacaEval from 19.0 to 38.5. Conclusion: that data is what gives the model its chat style.

**Our project is an ablation of sorts:** compare checkpoints one training stage apart to see what each stage adds.
